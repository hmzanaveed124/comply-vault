The homepage now positions ComplyVault around Prepare, Meet and Follow through while retaining the marketing site's existing green/coral palette, semantic tokens, cards, typography, Button, navigation and DemoForm. No new UI dependency or Ant Design migration.

## Availability boundary

- Current: recording upload, transcription, draft extraction, source-linked review, CCO/owner finalization and documentation exports. These reflect the existing public workflow; validate against the release being sold before merging.
- Product previews: client-first preparation, information gaps, conversation planning and live capture controls. No generally available or early-access enrollment claim.
- Integrations: no implied CRM, email, WhatsApp or live meeting connection from an upload capability.
- Security: homepage requests current security documentation rather than asserting unverified SOC 2 progress, universal tenant isolation, hosting geography or retention status.
- Measured results: the homepage no longer renders ROIStats. No unsupported customer metrics or speed guarantees replace it.
